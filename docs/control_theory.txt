import control as ctrl

def analyze_system(num: list, den: list) -> str:
    """
    输入传递函数的分子和分母系数，自动计算系统的性能指标。
    """
    try:
        # 1. 创建传递函数
        sys = ctrl.tf(num, den)
        
        # 2. 计算阶跃响应性能指标
        info = ctrl.step_info(sys)
        
        # 3. 拼接结果
        result = f"系统分析结果：\n"
        result += f"上升时间 (RiseTime): {info['RiseTime']:.2f} 秒\n"
        result += f"调节时间 (SettlingTime): {info['SettlingTime']:.2f} 秒\n"
        result += f"超调量 (Overshoot): {info['Overshoot']:.2f} %\n"
        return result
    except Exception as e:
        return f"计算失败，请检查输入格式，错误信息：{e}"
【自动控制原理核心知识与考研考点大全】

一、 时域分析核心指标（针对二阶系统）
1. 标准二阶系统闭环传递函数：G(s) = ωn^2 / (s^2 + 2ζωn*s + ωn^2)
2. 上升时间 tr = (π - β) / ωd，其中 β = arccos(ζ)，ωd = ωn*sqrt(1 - ζ^2)
3. 峰值时间 tp = π / ωd = π / (ωn*sqrt(1 - ζ^2))
4. 最大超调量 σ% = e^(-πζ / sqrt(1 - ζ^2)) * 100%
5. 调节时间 ts：在 5% 误差带下 ts ≈ 3 / (ζωn)；在 2% 误差带下 ts ≈ 4 / (ζωn)
6. 稳态误差 ess = lim(s→0) s * E(s)。对于阶跃输入，0型系统 ess = 1 / (1 + Kp)；I型系统 ess = 0。

二、 根轨迹绘制法则（8大法则，考研必考）
1. 起点与终点：根轨迹起于开环极点，终于开环零点（或无穷远）。
2. 分支数：根轨迹的分支数等于开环极点数 n。
3. 对称性：根轨迹关于实轴对称。
4. 实轴上的根轨迹：实轴上某一段右侧的开环实数零极点总数为奇数。
5. 渐近线：当 n > m 时，有 n-m 条渐近线。交点 σ = (Σp - Σz) / (n - m)，夹角 φ = (2k+1)π / (n - m)。
6. 分离点与汇合点：满足 Σ 1/(d - p) = Σ 1/(d - z)。
7. 出射角与入射角：出射角 = 180° + Σ(零点相角) - Σ(其他极点相角)。
8. 与虚轴交点：令 s = jω 代入特征方程，或者用劳斯表临界稳定条件求解。

三、 频域分析（Bode图与稳定裕度）
1. 幅频特性 L(ω) = 20lg|G(jω)|。相频特性 φ(ω) = ∠G(jω)。
2. 截止频率 ωc：L(ωc) = 0 dB 时的频率。
3. 相角裕度 γ = 180° + φ(ωc)。γ > 0 表示系统稳定。
4. 穿越频率 ωg：φ(ωg) = -180° 时的频率。
5. 幅值裕度 h：h(dB) = -20lg|G(jωg)|。h > 0 dB 表示系统稳定。
6. 最小相位系统：所有开环极点和零点都在左半 s 平面。

四、 劳斯稳定判据特殊情况（极其重要）
1. 首列出现0，但该行不全为0：用极小正数 ε 代替 0，继续计算。若 ε 上下符号变化，说明有正实部根。
2. 某行全为0：说明存在大小相等、符号相反的根（如纯虚根）。此时必须用上一行的系数构造辅助方程 P(s)，并对 P(s) 求导，用求导后的系数替换全零行。

五、 系统校正（PID与频域校正）
1. 比例-积分（PI）校正：提高系统型别，消除稳态误差，但会降低稳定性（相角滞后）。
2. 比例-微分（PD）校正：增加系统阻尼，提高稳定性，加快响应速度，但抗高频干扰能力差。
3. 超前校正：利用相位超前特性，提高相角裕度，改善动态性能。
4. 滞后校正：利用高频衰减特性，提高低频增益（减小稳态误差），但会降低截止频率。
